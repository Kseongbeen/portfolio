# AI 생성 영상 속 글자의 프레임 일관성 평가

## 1. 프로젝트 개요
텍스트-투-비디오 모델이 만든 영상 속 글자가 시간이 지나도 같은 모습으로 유지되는지를 정량적으로 평가하는 연구입니다. (AI+X 고급 프로젝트, 2026-2학기, 진행 중)

## 2. 문제 정의 / 동기
- 최신 비디오 생성 모델은 간판·표지판·자막 같은 글자를 그럴듯하게 그려 내지만, 영상이 진행되면서 글자 모양이 미세하게 흔들리거나 다른 글자로 바뀌는 현상이 자주 나타납니다.
- 사람이 보기에 거슬리는 이 현상은 영상 전체 품질 점수에는 잘 드러나지 않습니다.
- 생성 영상 속 글자를 다루는 벤치마크가 최근 나오기 시작했지만, 시간 축의 일관성을 직접 재는 방법은 아직 정리되지 않았다고 판단했습니다.

## 3. 접근 방식
- 영어·숫자 글자가 들어가도록 설계한 프롬프트로 여러 생성 모델의 영상을 만들고, 압축 손실이 섞이지 않도록 프레임 단위로 저장합니다.
- OCR과 영상 처리 기법을 결합해 프레임 사이 글자 변화를 정답 없이 측정하는 평가 지표를 설계하고 있습니다.
- 측정 결과를 생성 모델 개선 신호로 활용하는 방향까지 검토하고 있습니다.

> 논문 투고 전이라 지표 정의와 실험 결과는 공개하지 않습니다.

- 실험용 GPU 환경 구성 및 생성 영상 파이프라인 운영
