# 효능 내비게이터 — 해양바이오뱅크 계통 기반 효능 예측·추천

> 코드·제출 자료: [Kseongbeen/mabik-efficacy-navigator](https://github.com/Kseongbeen/mabik-efficacy-navigator)

## 1. 프로젝트 개요
아직 효능 시험을 하지 않은 해양생물 분양 자원에 효능 가능성을 표시하고, 목적에 맞는 자원을 추천하는 검색 서비스를 제안했습니다. (해양바이오뱅크(MABIK) 아이디어 공모전, 부문 3)

## 2. 문제 정의 / 동기
- 뱅크에는 1만 건이 넘는 효능 시험 결과가 공개되어 있지만, 분양 실적으로는 잘 이어지지 않습니다.
- 효능 시험을 하지 않은 자원은 학명과 채집지 정보만 있어 이용자가 근거 없이 골라야 합니다.
- 분양 한도와 소요 기간을 고려하면 자원을 잘못 골랐을 때 비용이 큽니다.

## 3. 접근 방식
- 공개된 효능 데이터와 자원 목록을 수집하고, NCBI 분류 정보로 생물 계통을 연결
- 같은 계통의 생물은 비슷한 물질을 만드는 경향이 있다는 점에 착안해, 효능이 계통을 따라 모여 있는지 분석
- 학습에 쓰지 않은 종을 맞히는 방식(종 단위 교차검증)으로 계통 기반 효능 예측 모델을 검증
- 예측 결과를 검색 화면에 표시하고, 분양 이후 성과가 다시 데이터로 쌓이도록 하는 서비스 구조와 화면 시안 설계

## 4. 본인 역할
- 개인 참가: 데이터 수집, 분석·모델링, 제안서 작성, 화면 시안을 모두 담당
