# HOP — 일상 통화 속 마음 변화 감지 서비스

## 1. 프로젝트 개요
멀리 떨어져 사는 가족의 일상 통화에서 말 너머의 변화를 알아차리도록 돕는 서비스를 기획했습니다. (HOP BioHealth AI Challenge, 심리상담 데이터 부문)

## 2. 문제 정의 / 동기
- 정신건강 진료는 방문 사이 공백이 길고, 치료 도중 이탈하는 비율도 높아 진료실 밖의 변화를 관찰하기 어렵습니다.
- 마음의 어려움은 "우울하다"보다 "잠을 못 잔다", "몸이 아프다"처럼 돌려서 표현되거나, 말수·침묵 같은 말하기 방식의 변화로 먼저 드러나는 경우가 많습니다.
- 가장 자주 이어지는 접점인 일상 통화에서 이런 변화를 발견할 수 있다면 도움이 필요한 시점을 앞당길 수 있다고 보았습니다.

## 3. 접근 방식
- 공개 통계와 교육용 청구 데이터로 진료 공백·이탈 현황을 분석해 문제의 크기를 확인
- 통화 속 발화를 기기 안에서 문자로 변환하고, **무엇을 말했는지(표현)** 와 **어떻게 말했는지(말속도·침묵)** 를 개인의 평소 기준선과 비교하는 구조 설계
- 변화가 며칠 이어질 때만 안부 전화나 상담 예약 같은 가벼운 행동을 제안하도록 설계

## 4. 본인 역할
- 팀 프로젝트(5인)
- 데이터 분석 및 EDA (공개 통계·교육용 청구 데이터)
- 아이디어 구상
