# 송AI지 — 한우 농장 HACCP 기록 자동화 앱 기획

## 1. 프로젝트 개요
한우 농장의 HACCP 기록 부담을 줄이고, 쌓인 기록을 출하 판단 정보로 돌려주는 모바일 앱 「한우 출하노트」를 공공데이터 분석을 바탕으로 기획했습니다. (2026 한국식품안전관리인증원 공공데이터 분석·활용 경진대회, 분석 부문)

## 2. 문제 정의 / 동기
- 공공데이터로 축종별 HACCP 인증 현황을 분석한 결과, 한우 농장의 인증률이 다른 축종에 비해 크게 낮았습니다.
- 원인을 두 가지로 정리했습니다.
  1. 평가 항목마다 손으로 기록해야 하는 부담
  2. 인증을 받아도 소 값에 반영되지 않는 보상 구조

## 3. 접근 방식
- 공공데이터 API로 인증업체·인허가 데이터를 수집하고, 축종별·지역별 인증 현황을 분석해 문제를 정의
- 해결안을 두 축으로 설계
  - **위생·안전:** 약 처방·판매 기록 연계로 투약 기록을 자동화하고 출하 전 휴약 기간을 자동 점검
  - **보상:** 축적된 기록과 이력 정보를 묶어 개체별 출하 판단과 월간 농장 성적표 제공
- AI는 꼭 필요한 곳(약 포장 인식 등)에만 적용하고, 고령 사용자를 고려한 화면을 설계
